## Search Console owner steps

1. Open the verified hegevaai.co.uk property.
2. Open Sitemaps.
3. Submit sitemap.xml if it is not already submitted.
4. Use URL Inspection for the priority URLs above.
5. If a new page is not indexed, run Test Live URL first.
6. Request indexing only after the live test passes.
7. Do not submit /go/* campaign redirect URLs for indexing.
8. Do not submit private product routes such as /login, /get-started, /account, /command-center or /business.

## Directory round 1

Use the product homepage or /challenge as the listing URL unless the directory specifically supports a tools page.

Priority:
- Product Hunt — maker/community launch.
- SaaSHub — SaaS directory; verify using the HEGEVA domain email where possible.
- AlternativeTo — suggest HEGEVA as a new application after account email verification.

Keep descriptions factual:
"HEGEVA AI is an approval-first AI workspace for small businesses that brings customers, quotes, invoices and follow-ups together and prepares the next action for the owner to approve."

Do not claim guaranteed time savings, guaranteed revenue growth or automatic business execution.
